**Steam SiteLink** is a plugin for the [Millennium](https://github.com/SteamClientHomebrew/Millennium) framework that adds search buttons for popular external direct-download and repacker sites to Steam game pages.

<img src="https://i.imgur.com/AfIcenE.png" alt="gui" width="750"/>


## Features

*   **Quick Search Buttons** - Adds buttons for configured external sites below the game title.
*   **External Browser Support** - Clicking a button opens the search results for that game on the corresponding site in your default external web browser
*   **Customizable Display Options** - Choose how buttons appear: Icons Only, Text Only, Both
*   **Site Visibility Control** - Enable or disable buttons for specific sites via the settings
*   **Button Reordering** - Easily change the order of the sites by right-clicking them

## Supported Sites
[Check out the RIN post](https://cs.rin.ru/forum/viewtopic.php?f=20&t=148068)

## Requirements

*   **[Millennium](https://steambrew.app/)** - Must be installed and running with Steam.

## Installation

1. Extract the `steam-sitelink` folder into your Millennium `plugins` directory:
    *   **Windows:** `%MILLENNIUM_PATH%\plugins\` for most this will be `C:\Program Files (x86)\Steam\plugins\`
    *   **Linux:** `~/.millennium/plugins/`
